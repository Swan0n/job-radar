# Job Radar

Собирает вакансии с пяти украинских сайтов, оценивает каждую относительно
твоего резюме и показывает только те, что действительно подходят. К каждой
вакансии можно одной кнопкой получить сопроводительное письмо, написанное
именно под неё.

Работает локально на твоей машине. Никакого сервера и никакой регистрации:
база лежит у тебя на диске, наружу уходят только запросы к сайтам вакансий
и к Claude API.

**Источники:** work.ua, robota.ua, djinni.co, jobs.dou.ua, LinkedIn.

---

## Что понадобится

- **macOS или Linux.** Ставить Xcode, Homebrew, Python или Node заранее не нужно —
  всё подтянется на шаге 1.
- **Ключ Claude API** и немного кредитов на нём. Это платно: считай 5–8 $ в месяц
  при ежедневном использовании. Подробности в разделе «Сколько это стоит».
- **Своё резюме** в PDF или DOCX.

## Установка

### 1. Поставь uv

Это менеджер окружения, который сам скачает нужный Python. Не требует
ни пароля администратора, ни Xcode:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Перезапусти терминал или выполни `source $HOME/.local/bin/env`.

### 2. Скачай проект

```bash
git clone https://github.com/ВАШ_ЛОГИН/job-radar.git
cd job-radar
```

Если git не установлен, скачай архив кнопкой **Code → Download ZIP** на странице
репозитория и распакуй.

### 3. Установи зависимости и браузер

```bash
uv sync
uv run playwright install chromium
```

Chromium весит около 100 МБ. Он нужен, потому что work.ua и robota.ua закрыты
Cloudflare и обычным HTTP-запросом не отдают страницы — их приходится открывать
настоящим браузером.

### 4. Впиши свой ключ Claude API

```bash
cp .env.example .env
```

Открой `.env` и замени заглушку на свой ключ:

```
ANTHROPIC_API_KEY=sk-ant-твой-ключ
```

Где взять: [console.anthropic.com](https://console.anthropic.com) → зарегистрироваться →
**Billing** → купить кредитов (минимум 5 $) → **Settings → API keys** → **Create Key**.
Ключ показывают один раз, копируй сразу.

Без кредитов на балансе ключ создастся, но запросы будут возвращать ошибку.

### 5. Положи своё резюме

Скопируй файл PDF или DOCX в папку `resume/`. Имя любое.

PDF должен быть с текстовым слоем. Если это скан или фотография, текст из него
не извлечётся — пересохрани резюме как DOCX.

### 6. Запусти

```bash
./scripts/run.sh
```

Открой <http://127.0.0.1:8777>

## Первый запуск в интерфейсе

1. В жёлтой плашке нажми **«Разобрать резюме»**. Claude прочитает его и соберёт
   профиль: роль, грейд, годы опыта, стек, а заодно подставит поисковые запросы.
2. Открой **«Настройки»** и проверь: запросы, города, формат работы, зарплатный
   ориентир, порог совпадения. Всё это меняется в любой момент.
3. Нажми **«Запустить первый сбор»**. Он берёт вакансии за 30 дней и занимает
   10–20 минут. Прогресс виден в шапке.

Дальше жми **«Обновить сейчас»**, когда захочешь свежих вакансий. Сбор сам
посмотрит назад до прошлого прогона, так что после перерыва ничего не потеряется.

По умолчанию ничего не запускается само: пока не нажмёшь кнопку, обращений к
Claude нет и деньги не тратятся. Если хочешь обновление по расписанию, включи
в настройках **«Обновлять автоматически каждый день»** и укажи время.

## Как считается процент

Итог складывается из четырёх измерений, веса настраиваются:

| Измерение | Вес по умолчанию | Кто считает |
|---|---|---|
| Навыки и стек | 40 | Claude, сравнивая требования с резюме |
| Опыт и грейд | 35 | Claude |
| Условия: формат, город, деньги | 25 | арифметика по твоим настройкам |
| Домен / индустрия | 0 | Claude |

Условия считаются локально, а не моделью: это обычная арифметика, поэтому в
карточке видно, из чего именно сложилась цифра, а не «просто 82%».

Зарплата работает мягко: вакансия ниже твоего ориентира теряет проценты, но не
исчезает. Большинство украинских вакансий вилку вообще не указывают, и жёсткий
фильтр вырезал бы половину хороших вариантов.

Вакансии от 70% попадают на вкладку «Подходящие», от 50 до 70 — на «Почти».
Порог двигается слайдером.

## Особенности источников

**work.ua и robota.ua** — общие джоб-борды, где есть все профессии. Их поиск
работает по словам, поэтому на запрос «SRE Engineer» они честно выдают
«Інженер-конструктор». Чтобы не платить за оценку такого, есть бесплатный отсев:
в названии вакансии должно быть хотя бы одно профильное слово из твоих запросов
или навыков. Для IT-профилей эти два сайта дают мало: если нужна скорость,
выключи их в настройках — они самые медленные из-за браузера.

**djinni.co** ищет не по свободному тексту, а по своему справочнику
специализаций (`python`, `dev_ops`, `qa_automation`, `data_science` и так далее).
Запрос, который в справочник не попадает, для Djinni пропускается — иначе он
вернул бы вообще все свои вакансии. Поэтому пиши запросы с названием технологии:
«Python Developer», а не «Backend Engineer».

**jobs.dou.ua** — RSS-лента. Самый быстрый и стабильный источник, полное описание
приходит сразу.

**LinkedIn** берётся через публичный поиск, который отдаётся незалогиненному
посетителю. **Вход в твой аккаунт не используется, аккаунт ничем не рискует.**
Это неофициальный путь, и LinkedIn периодически меняет разметку. Если он
отвалится, остальные четыре источника продолжат работать, а LinkedIn выключается
в настройках.

## Сколько это стоит

Оценка вакансий — самая массовая операция. При ~60 новых вакансиях за прогон:

| Модель | Примерно за прогон | Если гонять каждый день |
|---|---|---|
| claude-opus-5 | 0,40–0,60 $ | 12–18 $ в месяц |
| claude-sonnet-5 *(по умолчанию)* | 0,15–0,30 $ | 5–8 $ в месяц |
| claude-haiku-4-5 | 0,10 $ | 3–4 $ в месяц |

Первый сбор дороже обычного, потому что берёт 30 дней сразу: около 0,30–0,80 $
на Sonnet. Одно сопроводительное письмо — примерно цент.

Модель для оценки и модель для писем выбираются отдельно в настройках. Разумный
компромисс — Sonnet на оценку, Opus на письма: писем в месяц штучное количество,
и качество там важнее.

Расход снижают три вещи, уже включённые: бесплатный отсев до обращения к модели,
оценка пачками по 6 вакансий и кэширование профиля между запросами.

## Если что-то пошло не так

**«Нет ключа Claude API»** — в `.env` осталась заглушка `sk-ant-...` либо файл
`.env` вообще не создан. Впиши ключ и перезапусти сервис.

**Ошибка про недостаточный баланс** — ключ рабочий, но на счету нет кредитов.
Пополни в Billing на console.anthropic.com.

**Пустой список после сбора** — проверь поисковые запросы в настройках. Они
должны выглядеть так, как их вбивают в поиск на сайте: «Python Developer»,
а не «ищу работу».

**work.ua или robota.ua ничего не вернули** — Cloudflare иногда показывает
браузеру проверку. Обычно проходит само со следующего раза: профиль браузера с
cookie сохраняется в `data/browser_profile`. Если не проходит несколько дней —
удали эту папку.

**Резюме не читается** — скорее всего, PDF без текстового слоя. Пересохрани
как DOCX.

## Автозапуск (необязательно)

Чтобы сервис поднимался при входе в систему и переживал перезагрузку:

```bash
./scripts/install-autostart.sh
```

Сам по себе он ничего не тратит: без нажатия кнопки к Claude не обращается.

Выключить:

```bash
launchctl unload ~/Library/LaunchAgents/com.jobradar.app.plist
rm ~/Library/LaunchAgents/com.jobradar.app.plist
```

## Устройство проекта

```
app/
  main.py        HTTP-слой и маршруты
  pipeline.py    прогон: сбор → отсев → описания → оценка
  sources/       по модулю на каждый сайт
  llm.py         запросы к Claude: разбор резюме, оценки, письма
  matching.py    сборка итогового процента
  scheduler.py   необязательный ежедневный запуск
  db.py          SQLite
web/             интерфейс: чистый HTML, CSS и JS, без сборки
scripts/         запуск и автозапуск
data/jobs.db     вакансии, оценки, статусы и письма (создаётся сам)
```

Ничего из личного в репозиторий не попадает: `.env`, папка `data/` и твоё
резюме исключены через `.gitignore`.
